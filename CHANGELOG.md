# Changelog

## 0.1.0

- Follow actual Windows mouse confinement instead of fullscreen state.
- Use Deskflow's native Scroll Lock action, confirmed through its service log.
- Release automatic locks when confinement ends; preserve manual locks.
- Add tray controls, Ctrl+Alt+F12, optional Windows startup, and a test window.
- Include per-user install/uninstall scripts and portable Windows x64 packaging.
- Document verified Cities: Skylines II behavior and single-monitor limitations.
